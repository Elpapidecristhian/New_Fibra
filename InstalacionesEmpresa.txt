# 🗺️ Configuración del Sistema de Mapas

## 📋 Resumen del Sistema

El sistema implementa una **solución híbrida** de mapas con Google Maps como principal y OpenStreetMap como respaldo automático.

### ✅ Características implementadas:

- **🎯 Google Maps como principal** (mejor calidad y funcionalidades)
- **🔄 OpenStreetMap como respaldo** (gratuito y confiable)
- **👆 Botón "Mostrar en mapa"** al lado del input de ubicación
- **🗺️ Mapa oculto por defecto** (se muestra solo cuando se necesita)
- **📍 Búsqueda automática** de direcciones ingresadas
- **🖱️ Marcador arrastrable** para ajustar ubicación
- **🔗 Generación automática** de URLs de Google Maps

## 🏢 Para Producción Empresarial

### 1. **Configuración de Google Maps API**

#### Pasos para obtener API Key empresarial:

1. **Crear proyecto en Google Cloud Console**
   - Ir a: https://console.cloud.google.com/
   - Crear nuevo proyecto o usar existente

2. **Habilitar APIs necesarias:**
   - Maps JavaScript API
   - Places API  
   - Geocoding API

3. **Crear credenciales:**
   - Ir a "Credenciales" → "Crear credenciales" → "Clave de API"
   - Copiar la API key generada

4. **Configurar restricciones:**
   - Restricciones de HTTP referrer
   - Agregar dominios autorizados: `*.empresa.com`, `localhost:8080`

5. **Configurar facturación:**
   - Agregar método de pago (tarjeta de crédito)
   - Configurar alertas de presupuesto

### 2. **Configuración en la aplicación**

#### Opción A: Variables de entorno (Recomendado)
```bash
# En el servidor de producción
export GOOGLE_MAPS_API_KEY="TU_API_KEY_EMPRESARIAL"
export GOOGLE_MAPS_ENABLED="true"
```

#### Opción B: Archivo de configuración
```properties
# En application-prod.properties
google.maps.api.key=TU_API_KEY_EMPRESARIAL
google.maps.enabled=true
```

### 3. **Estimación de costos**

#### Uso gratuito mensual:
- **28,000 cargas de mapa** (gratis)
- **100,000 requests de geocoding** (gratis)

#### Costos después del límite gratuito:
- **Maps:** $7 USD por cada 1,000 cargas adicionales
- **Places API:** $17 USD por cada 1,000 requests
- **Geocoding:** $5 USD por cada 1,000 requests

#### Estimación para empresa mediana:
- **50,000 cargas/mes:** ~$154 USD/mes
- **100,000 cargas/mes:** ~$504 USD/mes

## 🚀 Instrucciones de Despliegue

### Para el equipo de DevOps/IT:

1. **Obtener API key empresarial** (siguiendo pasos anteriores)

2. **Configurar variable de entorno:**
   ```bash
   export GOOGLE_MAPS_API_KEY="API_KEY_EMPRESARIAL"
   ```

3. **Verificar funcionamiento:**
   - Abrir la página de agregar servicio
   - Verificar que aparece "Google Maps cargado correctamente"
   - Probar búsqueda de direcciones
   - Verificar que el marcador es arrastrable

4. **Monitoreo:**
   - Configurar alertas de uso en Google Cloud Console
   - Monitorear logs de la aplicación para errores de mapas

## 🔄 Sistema de Respaldo

### Funcionamiento automático:

1. **Intenta cargar Google Maps**
2. **Si falla:** Automáticamente cambia a OpenStreetMap
3. **Notifica al usuario** el tipo de mapa en uso
4. **Mantiene toda la funcionalidad**

### Ventajas del respaldo:
- ✅ **Cero interrupciones** de servicio
- ✅ **Funcionalidad completa** mantenida
- ✅ **Sin costos adicionales**
- ✅ **Transparente para el usuario**

## 📞 Soporte Técnico
